Park & Rec Class Sellout Watcher

How fast do Park & Rec classes sell out? Data-driven planning for the next registration day.

What this is

A free public dashboard that tracks how quickly local Park & Rec classes fill up during their registration windows. Watch which sections sell out in seconds, which linger for days, and which patterns predict competitiveness — by category, time-of-day, location, age, and price.

Data is collected continuously by a scheduled scraper polling each county's public registration system.

About the data

Each section's status (Available / Waitlist / Full / Unavailable) is polled on the cadence published on each season's analysis page. Polling resolution is the lower bound on observed sell-out times — any class that sold out within one poll cycle is recorded as "≤ N seconds."
