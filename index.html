Arlington Park & Rec — registration monitor

Why this exists: Arlington's most popular kids' classes can sell out within seconds of registration opening. This page surfaces each section's historical sell-out speed so parents can plan registration day — which classes to grab first, which need a backup choice, and which are safe to register for at leisure.

A scheduled GitHub Actions job polls the public WebTrac catalog and records each section's status (Available / Waitlist / Full / Unavailable) over time into the SQLite database below. The Sell-out speed table shows the upper-bound time it took for each section to transition from open to scarce — shortest first. Use the per-column filters in any table header to narrow results.
